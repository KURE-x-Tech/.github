# Project Overview & Requirements

This document provides a concise summary of the LunaNet LSIS-AFS reference implementation scope and the key functional and non-functional requirements used in this repository.

---

## Scope

The implementation focuses on software-defined digital signal processing for LSIS-AFS:

- Spreading code generation.
- Message framing and parsing.
- FEC and integrity protection.
- Baseband IQ generation.
- Decode and validation workflows.

---

## Requirement categories

The project tracks requirements in four broad categories:

- Correctness against LSIS-AFS signal and message definitions.
- Performance targets for encode/decode and test execution.
- Interoperability readiness across gateway milestones.
- Documentation and reproducibility for competition evaluation.
